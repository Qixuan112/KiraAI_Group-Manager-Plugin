
# 群聊管理插件 (Group Manager Plugin)

为 KiraAI 提供群聊管理功能，支持禁言、踢人、设置名片、群公告、精华消息、专属头衔、加群申请审批、成员变动感知等。

## 功能特性

### 核心功能（默认启用）
- ✅ **禁言/解除禁言** - 对指定成员进行禁言管理
- ✅ **设置群名片** - 修改成员群名片
- ✅ **撤回消息** - 撤回群内的消息
- ✅ **查询成员列表** - 查看群成员简要信息
- ✅ **查询成员信息** - 查看指定成员的详细信息

### 可选功能（需手动开启，均为独立开关）
- ⚠️ **踢出成员** - 将成员踢出群聊
- ⚠️ **全员禁言** - 开启/关闭全员禁言
- 📢 **群公告** - 发布/读取群公告（编辑公告=读旧公告后发布新版）
- ⭐ **精华消息** - 设置/取消/查看群精华消息
- 🏷️ **专属头衔** - 给群成员设置专属头衔（Bot 需为群主）
- 📥 **加群申请处理** - 定时轮询 + 主动查询待处理申请，Bot 可审批或私聊请示主人
- 👋 **成员变动感知** - 退群感知（注入对话环境）与新人入群欢迎（默认关闭）

> 成员查询增强：推荐搭配独立插件 **group_member_viewer**（群概览/关键词查找/成员详情）。
> 两插件可同时安装：检测到 viewer 时本插件会自动卸载自带的两个查询工具，避免重复。

## 安装

1. 将插件文件夹复制到 `data/plugins/`
2. 重启 KiraAI 或重新加载插件
3. 在 WebUI 中配置管理员（或手动编辑配置文件）

## 配置说明

配置文件位置：`data/config/plugins/group_manager.json`

v1.2.0 起配置按分组管理（WebUI 中按分组展示）。旧版平铺配置键仍被兼容读取：
**新分组配置优先；仅当新键保持默认值且旧键被改过时才沿用旧值**（日志会提醒迁移）。

### 权限与日志（section_admin）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `admin_qq_list` | 数组 | [] | **管理员QQ号列表**，只有这些用户可以使用群管功能（当 `allow_ai_autonomous` 为 `false` 时生效） |
| `allow_ai_autonomous` | 布尔 | true | **允许 AI 自主执行**：开启后，AI 自行决定发起的群管操作（如自动禁言违规用户）将跳过调用者身份检查，直接执行。关闭时，仅允许 `admin_qq_list` 中的用户命令执行 |
| `auto_check_admin` | 布尔 | true | 启动后自动检查 Bot 在各群是否为管理员，不是则日志提醒 |
| `log_operations` | 布尔 | true | 是否记录群管操作日志 |

### 高危功能（section_danger）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_kick_user` | 布尔 | false | 是否启用踢人功能（高危） |
| `enable_whole_ban` | 布尔 | false | 是否启用全员禁言功能（高危） |

### 群公告 / 精华消息 / 专属头衔（section_notice / section_essence / section_title）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_group_notice` | 布尔 | false | 启用群公告发布/读取 |
| `enable_essence` | 布尔 | false | 启用精华消息设置/取消/查看 |
| `enable_special_title` | 布尔 | false | 启用专属头衔设置。⚠️ QQ 限制仅**群主**可设置头衔，Bot 只是管理员时请勿开启 |
| `show_title_in_query` | 布尔 | true | 在成员查询结果中展示专属头衔（🏷️） |

### 成员变动感知（section_presence）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_leave_notice` | 布尔 | false | 退群感知：谁退了/被踢了会注入 Bot 的对话环境 |
| `enable_welcome` | 布尔 | false | 新人入群时自动发欢迎语 |
| `welcome_template` | 文本 | `欢迎 {nickname} 加入本群～` | 欢迎语模板，占位符 `{nickname}` / `{user_id}` |

### 加群申请处理（section_join_request）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_join_request` | 布尔 | false | 启用加群申请处理（依赖 NapCat `get_group_system_msg`） |
| `join_poll_interval` | 整数 | 10 | 轮询间隔（分钟）。纯 API 查询，不消耗 LLM 额度、不阻塞消息；0=关闭轮询 |
| `join_request_mode` | 枚举 | ask_master | `ask_master`=有把握就批、拿不准私聊问主人；`auto`=Bot 全权审批；`notify_only`=只私聊通知主人 |
| `master_qq` | 字符串 | "" | 主人 QQ 号（ask_master / notify_only 模式必填） |

工作原理：插件按间隔调用 `get_group_system_msg` 查询待处理申请（含被腾讯风控过滤的申请），
发现新申请后按模式分发——ask_master/auto 会触发 Bot 在群内决策（Bot 能看到申请人和验证消息），
notify_only 直接私聊主人。用户也可以随时自然语言问 Bot"有没有人要加群"主动查询。

## 使用方法

### 1. 设置管理员

在 WebUI 的插件配置页面，添加管理员QQ号或手动编辑配置文件：
```json
{
    "admin_qq_list": ["你的QQ号", "朋友的QQ号"]
}
```

### 2. 使用群管功能

管理员在群内@Bot并发出指令，例如：
```
@Bot 把发广告的禁言10分钟
@Bot 查看群成员列表
@Bot 设置我的群名片为"大佬"
```

### 3. 开启可选功能

如需使用踢人或全员禁言，修改配置：
```json
{
    "enable_kick_user": true,
    "enable_whole_ban": true
}
```

### 4. 配置 AI 自主执行

默认情况下，`allow_ai_autonomous` 为 `true`，AI 可以根据对话内容自行决定执行禁言等操作（例如检测到刷屏、辱骂时自动处理）。如果你希望只有管理员通过命令才能触发群管功能，可将该开关关闭。

#### 提示词配置建议（重要）

当开启 `allow_ai_autonomous` 后，建议在 KiraAI 的人设提示词或群聊指令中根据需要加入以下规则，以确保 AI 正确区分“用户命令”与“自主判断”，避免被普通用户利用：

```markdown
## 群管操作安全规则
- 当用户**直接命令**你执行禁言、踢人等操作时（例如“把某人禁言”），你**必须**先确认该用户是否在你的管理员列表中。如果不在，应礼貌拒绝并说明“你没有权限”。
- 只有当你**自主判断**用户行为违规（如刷屏、辱骂、广告）时，你才可以**主动**调用群管工具，无需等待用户命令。
- 执行任何群管操作前，请简要说明原因（例如“检测到刷屏，禁言3分钟”）。
- 如果操作失败（如Bot不是群管理员），请提示用户联系群主设置Bot为管理员。
```

将上述提示词添加到 KiraAI 的角色设定中，可增强安全性，避免普通用户通过诱导 AI 执行违规操作。但并非绝对安全，请自行斟酌风险来是否开启一些高危选项。

## 权限说明

### 管理员验证
- 当 `allow_ai_autonomous` 为 `true` 时：
  - AI 自主发起的操作（非用户命令）直接放行
  - 用户命令仍会检查调用者是否在 `admin_qq_list` 中
- 当 `allow_ai_autonomous` 为 `false` 时：
  - 只有 `admin_qq_list` 中的QQ号可以使用群管功能
  - 机器人自身（系统消息、定时任务）通过 `allow_bot_self` 单独控制
- 非管理员调用工具时会返回：`❌ 用户不是插件的管理员`

### 群管权限
- Bot需要是**群管理员**才能执行群管操作
- 如果Bot不是群管理员，操作会失败

## 安全设计

1. **分层权限控制** - 区分用户命令与 AI 自主执行，支持灵活开关
2. **高危功能开关** - 踢人和全员禁言默认关闭，需手动开启
3. **操作审计日志** - 所有群管操作记录到日志，便于追溯
4. **错误提示明确** - 权限不足时明确告知原因
5. **提示词安全建议** - 提供示例规则，防止 AI 被滥用

## 故障排查

### 操作失败，提示"用户不是插件的管理员"
- 如果是由用户命令触发的：检查你的QQ号是否已添加到 `admin_qq_list`
- 如果是 AI 自主发起的：检查 `allow_ai_autonomous` 是否为 `true`
- 重新加载插件使配置生效

### 操作失败，提示"Bot不是群管理员"
- 在群设置中将Bot设为管理员

### 踢人/全员禁言功能不可用
- 检查配置中是否开启了 `enable_kick_user` / `enable_whole_ban`

### 获取适配器失败
- 检查Bot是否正常连接到QQ
- 查看日志中的适配器名称是否正确
